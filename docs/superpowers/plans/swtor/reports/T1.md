## Decisions
- Non copies : Gr2Skeleton, ImageColor/PaletteTint/TgaReader/TgaWriter, Gom, Jka/*, lecteurs d'index d'apparence (personnages uniquement). Rien n'en depend dans le code copie.
- `Gr2Reader` conserve toutes les voies de vertex (skin, couleurs, UV2/3) ; inutile pour l'archi mais gratuit.
- Le test d'extraction `.tor` n'est pas porte (TorNames/TorExtractor non copies).

## Faits mesures (art/static/area/crl_corellia/arch, 501 gr2)
- Les 501 fichiers de crl_corellia/arch parsent sans echec. (Dossiers du depot : `art/static/area/<planete>/arch/<theme>/`, ex. `arch/city/` ; textures dans `arch/city/texture/*_d.dds`, `_n.dds`.)
- Vertex layout : seulement 2 combinaisons. `Position|Core` (Core = normale + tangente + UV principal), presque toujours 1 jeu d'UV ; et `Position` seul (485 meshes), qui est le mesh de collision. Pas de couleurs, pas de skin, pas d'UV2/3 dans cet echantillon.
- Plusieurs meshes par fichier : 485/501 fichiers. Presque toujours un mesh visible + `generated_collision` (Position seul, sans UV/normales, geometrie differente et en general plus dense). On trouve aussi `collision`, `collision_override`, et des meshes `Object0x`/`Box0x` (parfois des doublons du mesh principal, ex. tram_gantry : `Object04` et `crl_arch_city_tram_gantry_T` ont tous deux 41426 v / 26788 tris). Il n'y a pas de LODs multiples dans un fichier ; les LODs sont des fichiers separes (`*_lod.gr2`, `*_lod_01.gr2`, 3 dans crl_corellia) a ignorer.
- Exemples :
  - `crl_arch_building_112x112_01.gr2` : mesh visible 1984 v / 1490 tris, 3 pieces (une par materiel) ; collision 2844 v / 1306 tris ; bbox X -6.17..6.17, Y 0..33.15, Z -6.17..6.17 (12.35 x 33.15 x 12.35).
  - `crl_arch_buildings_dam_card_01.gr2` : quad de 4 v, 15 x 15, plat (epaisseur ~0).
  - `crl_arch_city_island_foundation_lights_lip.gr2` : 26 v / 16 tris, 1.65 x 0.70 x 12.8.
  - `crl_arch_city_tram_gantry_t.gr2` (3.3 Mo) : 4 meshes, 41426 v / 26788 tris, 25.6 x 1.2 x 13.6.
  Y est la verticale, pied a Y=0, pieces centrees en X/Z. Les dimensions rondes (6.4 = 12.8/2, 7.5, 15, 25.6) indiquent des modules de grille ; **1 unite semble etre 1 metre pour l'architecture statique** (un batiment de 12 x 33 m, des dalles de 12.8 m), contrairement aux personnages (1 unite = 10 m dans le depot d'origine). A confirmer en T4 en comparant avec la taille des portes/personnages dans une zone.
- Materiaux : `Gr2Model.Materials` donne des noms sans extension (`crl_arch_city_foundation`, `crl_arch_buildings_windows`, ...) ; chaque `Gr2Piece.MaterialIndex` y renvoie. Chemin du .mat : `art/shaders/materials/<nom>.mat` (nom exact, pas de `[bt]` pour l'archi). Sur les 129 materiaux distincts de crl_corellia/arch, 129 .mat existent et 129 ont un `DiffuseMap` dont le `.dds` existe. Le dossier `materials` contient ~26 958 .mat.
- .mat : shader (`Derived`) = `Uber` (126), `Glass` (2), `NoShadeTexFogged` (1). Entrees : `DiffuseMap` (129), `RotationMap1` (= normale, 128), `GlossMap` (souvent `art\defaultassets\black`), `EmissiveMap` (31), `UvScaling`/`UVScaling` (valeur "1,1" dans les echantillons, type `uvscale`, non lu par `MaterialReader` en tant que tel), `DesignHue*`/`PlayerHueMap` (3), `GlassParams` (2). Les chemins de textures utilisent `\` et n'ont pas d'extension (`MaterialDef.TexturePath` les normalise ; ajouter `.dds`). `AlphaMode` None/Test/... disponible.
- DDS : `crl_arch_city_foundation_d.dds` 512x512 decode en RGBA 1 048 576 octets (BC1/BC3 etc. supportes ; pas de BC7).
- Nombre de gr2 par planete (tous themes confondus) : crl 653, all 8656, hth 709, ond 744, iok 653, mak 647...
