## Conception
- « Source de jeu » = `KotorGame` étendu (`Swtor`) : préfixe pk3/shaders/dossier `swtor` (`swtor_<map>.pk3`, `textures/swtor/<matériau>`), `ExportOptions.ForGame`,
  `ShaderNames.StripPrefix`. `PipelineSteps.ConvertObjects` renvoie vide pour SWTOR (placeables KOTOR non applicables).
- `Swtor.Pipeline` référence Kotor.* et Swtor.Core (Swtor.Core reste sans dépendance KOTOR). `ISwtorModelSource` abstrait le disque (tests sans jeu).
- Builder : instances `Kind==Model`, room `skyscene_room` ignorée, meshes `*collision*` ignorés, matériaux `util_collision*` masqués, GR2 en cache par chemin,
  monde = `AreaLayout.World`, conversion (x,y,z)->(x,-z,y) (rotation propre, sans retourner le sens des triangles), UV v inversé (`1-v`, le pipeline réinverse),
  `UvScaling` du .mat appliqué. Un `SceneMesh` par (room, matériau).
- Matériaux : .mat -> `DiffuseMap` -> DDS -> `KotorTexture` (réduit à 512 px max) -> TGA ; une clé/shader par matériau. `AlphaMode` Test -> cutout (`alphaFunc GE128`),
  Full/Multiply -> blend, Add -> additif, Glass -> blend alpha 110 uniforme. Shader sans lightmap (`UnlitCutout` ajouté, double face).
- Éclairage : ambiante plate 0,55 + 23 lumières ponctuelles à rayon deviné (2,5–8 m) via `SceneLight` ; pas de lightmap (T5).
- Collision : la géométrie visible sert de walkmesh (normale Z >= 0,7 marchable, le reste solide ; additifs exclus) ; le compilateur fait les brosses.

## Validation axes / Euler (point 4)
- Winding : sur les 33 906 triangles non collision de la zone, `cross(arêtes) · normale > 0` partout dans le GR2 brut ; idem pour les 159 617 triangles de la scène
  (0 incohérent) -> repère direct, la rotation propre est cohérente, pas de miroir imposé par les données (`--axes mirror` reste disponible).
- Dalles `mod_floor_plain` : (x, z) multiples de 3,2 m après composition parent/enfant (test d'intégration).
- **Constat** : `qx*qy*qz` applique en réalité Z puis Y puis X, pas « X d'abord » comme écrit en T2. Code inchangé (les lacets purs n'en dépendent pas) ;
  mes sondes statistiques (orientation des fines pièces floor/wall sur 120 zones, appartenance à l'emprise) ne départagent pas les 6 ordres.
  **Reste ouvert** : à trancher visuellement en T7 sur une pièce multi-axes (ex. `(90,90,0)`, `(0,90,90)`), et le sens miroir sur un panneau texte.
