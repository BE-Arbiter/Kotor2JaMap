## Décisions

- **CogLite conservée** (T5, `JkSurfaceEffects`, `JkThingConverter`) : elle fonctionne et ses tests passent ; la remplacer par `CogReader` sans changer le comportement de T5/T7 demande un travail de
  non-régression que cette tâche n'exige pas. Les deux lecteurs coexistent (`Jk.Pipeline.CogSymbol`/`CogCall` internes vs `Jk.Core.Cog.CogSymbol`/`CogCallSite` publics ; alias dans `CogClassifier`).
  À fusionner quand T9 touchera ces fichiers.
- **Règles du classifieur** (détail dans le catalogue) : `killed` -> `ActorTriggered` (le secteur est celui du thing mobile : la porte est là où le joueur passera) ; message d'utilisation + surface citée
  (`SetWallCel`, condition sur l'émetteur, négations exclues) -> un `SwitchMove` par surface, `Frames` = images envoyées puis retour (`[1,0]` pour `00_elev_switch`, `[floorlevel]` pour un bouton d'appel de
  `00_elevcall`) ; message d'utilisation sans surface -> `TouchDoor` ; `entered`/`crossed` -> `TouchDoor` si le COG appelle `SectorAdjoins` (c'est une porte), sinon `TwoStopLift` ; un COG qui a
  `crossed` ET un bouton (`00_elev_switch`) produit les deux (T9 choisit : l'automatique d'abord, le bouton en secours).
- **Déplacement à plusieurs destinations** (`C2_MTRIGELEV` : images 1 ou 2 selon l'émetteur, retour à 0) : `TwoStopLift`, pas `MultiStepPath`. `MultiStepPath` exige des étapes successives (un message de suite
  va vers une image nouvelle, ou deux déplacements sans condition vers deux images) ou un va-et-vient lancé par le COG seul (`08_elev4`, `C3_DUALELEV` : boucle).
- **Messages de suite** (`timer`, `pulse`, `arrived`) sans déclencheur direct : rattachés aux messages qui armeront la minuterie / enverront un message / déplaceront autre chose (copie marquée `Chained`),
  sinon à tous les déclencheurs du COG ; ainsi `16a_calamity` (`crossed -> SetTimer -> timer -> MoveToFrame`) et `00_elev_doors` (machine à états sur `arrived`) sont reconnus.
- **`Unsupported` = mouvement par un verbe non reproduit sur un thing SANS images** (rien pour reconstruire) ; avec images : `Approximate`. Les verbes d'exécution (`SetThingVel`, `SetThingPos`,
  `SetThingLook`) ne comptent que sur un thing à images : sinon `CTF_MAIN` (téléportation du drapeau) donnerait 6 `Unsupported` faux (constaté au premier passage sur les données).
- **Script absent** : pas de comportement fabriqué, `LevelMovers.MissingScripts` ; les things à images qu'il aurait pu déplacer restent `Approximate`.
- **Things à images non déplacés par un COG** : `Approximate` (raison : « no COG moves this thing » ou « COG x references this thing but ... »), pour que rien ne disparaisse (point de vigilance 1) ; c'est T9 qui
  place la position « passage ouvert » pour les `Approximate`/`Unsupported`.
- **Acteurs** (`type=actor` après résolution du gabarit, même avec images) : jamais mobiles, jamais classés.
- `FrameSequence` de la base est distinct de `Frames` de `SwitchMove`/`MultiStepPath` (même nom impossible avec un `record` positionnel).

## Préoccupations

1. **Classement sur le texte, sans exécuter le script** : la correspondance bouton -> images repose sur les conditions et sur les surfaces citées dans le message ; les machines à états complexes
   (`00_elev_doors`, `19_payload`, `18_ventpuzzle`) donnent des `SwitchMove` plausibles mais approximatifs (plusieurs surfaces pour un même thing). T9 doit traiter `SwitchMove` comme « déclenché par
   l'une de ces surfaces » et pouvoir se rabattre sur l'approche du joueur.
2. **`Delay`** : premier `SetTimer`/`SetTimerEx` hors `startup`, sinon un `Sleep` après le mouvement ; un délai calculé à l'exécution (`randsleep`) donne `null` (considéré « ne revient pas » : à relire pour
   `08_elev4`, qui est en boucle de toute façon).
3. **`TouchDoor` sans interrupteur** couvre les portes ouvertes par `activate` : en JK le joueur appuie sur la touche d'utilisation ; en JA une `func_door` s'ouvre au toucher (la spec le prévoit). Les portes
   verrouillées par clé (`00_doorkey`, `19_keydoor`) sont classées comme les autres ; la spec demande de les ouvrir (T9).
4. **`SurfaceCelSwitch` (244)** compte aussi les grilles coupées au sabre (`00_slashgrate`, `damaged`) : ce sont des changements de cellule + `SetAdjoinFlags` ; seul le côté texture est classé ici, l'ouverture
   du passage n'est pas un thing (la géométrie est déjà convertie visible).
5. **`17a_Stream.cog` absent** des GOB : à journaliser (`JK_COG_MISSING`) ; son effet (cours d'eau de `m_boss17`) est inconnu.
6. **CogLite** et **CogReader** coexistent (voir Décisions) : deux lecteurs de COG à maintenir tant que T5/T7 n'ont pas migré.
7. Kotor2Ja.App n'a pas verrouillé de DLL : `dotnet test Kotor2Ja.sln` est passé d'un seul tenant.
