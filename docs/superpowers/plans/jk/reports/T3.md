## Formats constates sur les donnees (a reporter dans jk-formats.md)

- CMP : en-tete 64 octets ("CMP ", 0x1E, indicateur transparence), 768 RGB, 64x256 tables de lumiere, 65536 de transparence si l'indicateur. Tailles 82752 et 17216 conformes. Fichiers sous `misc\cmp\` (Res2.gob), ex. `01narsh.cmp`.
- MAT : en-tete 76 octets : type @8 (0 couleurs, 2 textures observe), cellules @12, blocs @16, mode @20 (0 indexe), bpp @24. Les 1983 MAT de Res2 sont 8 bits indexes (mode 0) ; les champs de canaux sont du bruit pour 8 bits. Le 16 bits suit la specification et n'est verifie que par tests synthetiques.
- En-tete de cellule : 24 octets (couleurs : 0, indice de palette, 4 flottants, 0) ou 40 octets (textures). Bloc de donnees : largeur, hauteur, transparence, 2 inconnus, nombre de mipmaps, puis mipmaps (taille verifiee a l'octet sur 00d6x6). Seul le niveau 0 est decode.
- Les MAT de Res2 sont dans `mat\` (748) ET `3do\mat\` (1235), total 1983. `AllMatsInRes2_Decode` couvre les deux dossiers.
- Index 0 transparent seulement si l'indicateur de transparence du bloc est a 1 (cas 8 bits).
