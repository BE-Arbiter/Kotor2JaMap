  `modelscale` = `JkMd3.ModelScale`, collision de face (`collide=3`, jamais pour un objet destructible, plafonds 800 triangles/modèle, 60 000/niveau).
- Rotatifs (`PureRotation` ou `angvel`) : `func_rotating` + `model2` + sous-modèle sans contenu (`textures/jk/mover_nonsolid`) ; axe X/Y/Z, `JK_ROTATION_APPROX`
  si l'axe n'est pas simple, si le centre est décalé, ou si le modèle a un `modelscale > 1` (placé sans tourner).
- Animés (`Frames > 1`) : `misc_model_breakable` AUTOANIMATE (voir ci-dessous).
- Lumières de thing : `light`. Explosifs (COG avec message `damaged`) : décor + `JK_EXPLOSIVE_STATIC`. Things créés par COG : `JK_RUNTIME_THING`.
- Sons de secteur : `target_speaker` en boucle, wav copiés sous `sound/jk/` (mono), fusion des voisins de même son (2 unités JK, jusqu'à 12 si > 96
  haut-parleurs, `JK_SOUND_SKIPPED` au-delà), `JK_SECTOR_SOUND`, volumes non appliqués (un speaker JA n'a pas de volume).
- Volumes (T5) : eau = `func_static` + sous-modèle `CONTENTS_WATER` (un par couleur de brouillard, shader `WaterVolumeShader`) ; blessure et mort = `trigger_hurt`
  + sous-modèle `CONTENTS_TRIGGER`. **Vérifié : un brush `trigger_hurt` n'est pas solide** (`HurtSector_BecomesTriggerHurt_NeverSolid`,
  `FullChain_WaterTriggerAndFan_CompileToTheBsp` lit les contenus dans le BSP compilé). Brush = plans du secteur s'il est convexe, sinon boîte englobante.
  Journal : `JK_WATER_BRUSH`, `JK_HURT_TRIGGER`, `JK_VOLUME_DEGENERATE` ; `JK_WATER_VOLUME` (T5) renvoie maintenant vers `JK_WATER_BRUSH`.
  Le brouillard sous l'eau n'est pas converti (dit dans le journal).
