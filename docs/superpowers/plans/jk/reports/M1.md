### Comment JK choisit la musique

- Pas de fichier de configuration par niveau : ni `episode.jk` (colonnes ligne / CD / niveau / type / fichier / gotos), ni les `.uni`, ni les `.jkl` (aucune section ni cle « music ») ne parlent de musique.
- C'est un COG par niveau, au message `startup`, qui appelle `PlaySong(debut, fin, retour)` (numeros de pistes **CD**, d'ou les fichiers `TrackNN`). Les COG concernes (tous les `.cog` des GOB ont ete lus) :
  - `00_soundtrack.cog` (Res2) : `PlaySong(starttrack, endtrack, loopto)` avec les 3 premiers arguments de l'instance (`00_soundtrack.cog 13 13 12`) : 22 niveaux ;
  - `01_SoundTrack.cog` (JK1.GOB, niveau 01) : meme appel, puis `SetMusicVol(0.0)` : la musique demarre **muette**, un `crossed` sur deux adjoins la monte (+0,05 par 0,1 s) ou la coupe (-0,1) : elle ne joue que dans le bar d'ouverture ;
  - `06a_startlevel.cog` : `PlaySong(6, 7, 6)` ; `09_startlevel.cog` : `PlaySong(2, 4, 2)` (valeurs litterales) ; `06b_startlevel.cog` a `PlaySong(6, 7, 6)` mais `06bbarons.jkl` ne l'instancie pas ;
  - `levelsong.cog` : `PlaySong(cdtrack)`, une seule piste, instancie dans aucun niveau.
- Semantique : `debut`, `debut+1`... jusqu'a `fin`, puis retour a `retour` et jusqu'a `fin`, sans fin. Dans les 17 combinaisons reelles on a toujours `retour <= debut <= fin` : la suite jouee est **le cycle `retour..fin` lu a partir de `debut`**.
- Autres appels de musique : seulement `SetMusicVol` (baisse a 0,3 pendant un dialogue et retour a 1,0) dans `07_rahnlines`, `11_endlevel`, `15_rahnlines`, `17a_rahnlines`, `20_rahnlines`, `21_rahnlines`. Pas de `ChangeTrack`, pas de musique dynamique (le jeu n'enchaine pas des themes selon les evenements : les donnees montrent un seul `PlaySong` par niveau).

### Comment JA / SWGL joue la musique de fond (OpenJK-SWGL, `C:\Users\lambe\source\repos\OpenJK-SWGL`)

- `g_spawn.cpp:1499` : la cle `music` du worldspawn (`"music" "intro [boucle]"`) va dans `CS_MUSIC` ; `cg_main.cpp:CG_StartMusic` la lit (deux mots : intro puis boucle) et appelle `S_StartBackgroundTrack(intro, boucle)`. `target_play_music` (`g_target.cpp:1183`) fait de meme sur un declenchement (cle `music`, « WAV or MP3 »).
- `snd_dma.cpp:S_StartBackgroundTrack` : extension par defaut `.mp3`. **Si le nom contient un `/` et que le fichier existe, c'est une musique non dynamique** (lue en flux, jouee en boucle quand la boucle est vide) : **aucun `.mus` ni `dynamicmusic` n'est necessaire**. Les `.mus` / `ext_data/dms.dat` (`snd_music.cpp`) ne servent que si ce fichier n'existe pas (musique dynamique explore/action/boss, specifique aux niveaux de JA).
- Formats (`S_StartBackgroundTrack_Actual`) : MP3 (decodeur interne) **ou wav PCM** (en-tete `fmt ` puis `data`, flux depuis le fichier ; un avertissement si ce n'est pas du 22 050 Hz stereo, mais `S_RawSamples` reechantillonne au plus proche voisin et accepte mono ou stereo 8/16 bits). **Pas d'Ogg Vorbis** (le code ne le connait pas : un `.ogg` ne peut pas etre joue tel quel).
- Emplacement : n'importe quel chemin du pk3 ; KOTOR utilise `music/<dossier-du-jeu>/<nom>.mp3`. On prend `music/jk/<niveau>.wav` (le nom complet avec son extension, pour que le moteur ne rajoute pas `.mp3`).
- Boucle (`S_UpdateBackgroundTrack`) : a la fin du fichier le moteur rouvre `sMusic_BackgroundLoop` (egal au fichier si la boucle est vide) ; le test de presence ajoute `.mp3` seulement quand le nom n'a pas d'extension, ce qui n'est pas notre cas.

### Conversion necessaire et dependance

Le format JK (Ogg) n'est pas lu par JA : conversion obligatoire. Aucun decodeur Vorbis dans le depot ; aucun encodeur MP3 (ni ffmpeg, ni lame). Les DLL du jeu sont x86. Choix : **NVorbis 0.10.5** (NuGet, bibliotheque Vorbis geree, MIT, `netstandard2.0`, deja dans le cache NuGet local) pour decoder, sortie en **wav PCM 16 bits stereo 22 050 Hz** (filtre sinc fenetre Blackman avant la decimation par 2 pour ne rien replier). Un wav pese 88,2 Ko/s contre ~40 Ko/s pour l'ogg d'origine et ~16 Ko/s pour un MP3 128 kbit/s : le prix de n'avoir ni encodeur MP3 ni dependance native. Alternatives ecartees : encoder en MP3 (Media Foundation / lame : dependance Windows ou native), wav 11 025 Hz (meme taille que l'ogg mais bande passante 5,5 kHz).

### Choix et approximations

- Un seul wav par niveau avec toutes les pistes du cycle dans l'ordre de JK (exactement la suite jouee par JK, sans doublon) : pas d'intro separee ; le moteur reboucle sur le meme fichier.
